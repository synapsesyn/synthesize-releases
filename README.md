# Synthesize

A custom lightweight spotify client.

## Download

**[Download Synthesize (synthesize.zip)](https://github.com/synapsesyn/synthesize-releases/releases/latest/download/synthesize.zip)**

1. Unzip `synthesize.zip`.
2. Open the `Synthesize` folder and double-click **Install Synthesize.cmd**.
3. Open it any time from the Start menu: press the Windows key and type "synthesize".

If i push updates. Just close and reopen it. It updates itself.

The README.txt inside the zip explains how to sign in with your own Spotify Client ID.
